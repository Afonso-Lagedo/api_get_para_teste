# Mudando a configuração do sistema operacinal para instalar o node e afins:

- abrir o power shell como admin:

- digitar o comando: Set-ExecutionPolicy RemoteSigned
- 's' para sim!

# instalando o projeto a primeira vez:

- no termianl: npm init -y
- npm install express
- criar o arquivo index.js

# instalando projeto pronto:

- git clone URLDOREPO
- no terminal: npm install / npm i
- node index.js

# rodar projeto:

- no terminal: node index.js 
- no navegador: localhost:3005

# rate-limit: 

- no terminal: npm install express-rate-limit
